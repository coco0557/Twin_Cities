Workshop 14: Generating a RSS feed from MySQL tables

Workshop goals and expected learning outcomes:
  • familiarization with the RSS feed standard;

Create a directory called ws14 under the htdocs directory to hold the files for this workshop.

Completing this workshop will give you a working example to modify & use for the RSS generation required in the Assignment task.

Workshop Tasks

  1. Download the following ZIP file: quotes-db.zip to extract the quotes-db.sql file;
  2. Copy the quotes-db.sql file to your ws16 directory;
  3. Start Apache & MySQL services using the XAMPP control panel;
  4. Use the [ ] tab in the PHPMyAdmin interface to import the quotes-db.sql into the databse;
  5. Ensure the DB has been created and you have four tables with data.

Task 2: Formulate the required SQL query

RSS is best suited to rapidly changing data - news, weather, stock and commodity prices, currency exchange rates etc. - and it should ideally send out the latest data.

Notice that our quotes records include a timestamp (ts) field and the last two records are in January. We will filter on this field and only return the four records after January.

Copy the following SQL and run it using PHPMyAdmin - use the [ ] tab whilst in the quotes-db database.

SELECT `qid`, `quote`, `s-name`, `wpimg`
FROM `quotes`, `source`
WHERE `sid` = `sid-fk` AND MONTH(`ts`) > 1;
